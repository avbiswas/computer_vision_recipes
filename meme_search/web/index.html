Meme search

Describe a situation in words. The search finds a blank meme template that fits it and puts your words into the text boxes.

Model: CLIP ViT-B/16, fine-tuned · Data: MemeCap (6,416 memes; 2,000 templates in this demo) · Runs in your browser

How it works

Most meme search tools read the text printed on the meme. A blank template has no text, so the search must work from the picture only. This project teaches CLIP to connect a situation, for example "my code compiled after 6 hours", with the picture of the right template.

Data preparation (offline, one time)

  1. Find the text. Florence-2 reads the text on each MemeCap meme and gives a box for each line.
  2. Make a mask. The text boxes become a black-and-white mask: white where the text is.
  3. Remove the text. An inpainting model (LaMa) fills the masked area with a background that matches the rest of the picture. The result is a blank template.
  1. Save the text boxes. We keep the position, line height and color of each box, so new text can go back in the same place.
  2. Fine-tune CLIP. We train CLIP ViT-B/16 on pairs of (blank template, caption), so it learns to match situations with pictures that have no text.
  3. Build the index. We save one 512-number vector for each template in one flat file.
  4. Pick the web subset. We keep 2,000 of the 6,416 templates: k-means picks them so that every kind of meme stays in.

Inferencing (online, in your browser)

  1. The CLIP text encoder turns your words into a 512-number vector.
  2. The page computes the dot product with every row of the index. This takes a few milliseconds, so no vector database is necessary.
  3. The page shows the 6 best templates and hides near-duplicates.
  4. Your words go into the text boxes of each template.
  5. If the words do not fit, the page removes the least important words. A word is important if the match score drops a lot without it.

Papers and links

  • Learning Transferable Visual Models From Natural Language Supervision (CLIP) (Radford et al., 2021). The model and the contrastive loss.
  • MemeCap: A Dataset for Captioning and Interpreting Memes (Hwang and Shwartz, 2023). The memes and the three caption types.
  • Florence-2: Advancing a Unified Representation for a Variety of Vision Tasks (Xiao et al., 2023). OCR with boxes.
  • Resolution-robust Large Mask Inpainting with Fourier Convolutions (LaMa) (Suvorov et al., 2021). Removes the text.
  • OpenCLIP. The training code for CLIP.
