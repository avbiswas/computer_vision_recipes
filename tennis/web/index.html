How it works

Broadcast tennis video goes in. The ball, both players and the 14 court keypoints come out, plus a top-down minimap. One small network does all three tasks at about 200 frames per second.

The model

  1. Input. 3 consecutive grayscale frames are stacked as channels, so the moving ball is visible in one input.
  2. Encoder. A ResNet-18 without its last stage (that stage has most of the weights, and heatmaps need fine detail).
  3. Decoder. A U-Net decoder brings the features back to half the input size.
  4. Output. 16 heatmaps (1 ball, 14 court points, 1 player center) plus the width and height of each player box.

From heatmaps to the minimap

  1. The brightest peak of each heatmap gives a point: the ball, a court point or a player center.
  2. The 14 court points give a homography: a 3 × 3 matrix from the camera view to a top-down court.
  3. The homography maps the players' feet (the bottom of each box) onto the minimap.
  4. A racket hit is a frame where the ball changes vertical direction near a player.

Labels (offline, one time)

  1. The public dataset (TrackNet) labels only the ball.
  2. Grounding DINO finds every person. A filter keeps the 2 players (it drops boxes that never move: judges and crowd).
  3. A pretrained court detector finds the 14 court keypoints. One homography per clip removes its mistakes.
  4. The small model learns all three tasks from these labels. This is distillation: slow models make the labels, and a fast model learns to copy them.

Papers and links

  • TrackNet: A Deep Learning Network for Tracking High-speed and Tiny Objects in Sports Applications (Huang et al., 2019). The ball dataset, and the idea of heatmaps from stacked frames.
  • Objects as Points (CenterNet) (Zhou et al., 2019). Heatmap centers + sizes, and the focal loss we use.
  • Grounding DINO: Marrying DINO with Grounded Pre-Training for Open-Set Object Detection (Liu et al., 2023). Player labels from a text prompt.
  • Deep Residual Learning for Image Recognition (ResNet) (He et al., 2015) and U-Net (Ronneberger et al., 2015). The encoder and the decoder.
  • Distilling the Knowledge in a Neural Network (Hinton et al., 2015). Large models teach a small model.
  • TennisCourtDetector and TrackNet (PyTorch) by yastrebksv. Court labels and the dataset download.
