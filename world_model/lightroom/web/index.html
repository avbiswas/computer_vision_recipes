World model: a playable dream of a room

A small room has boxes, a flashlight and fireflies. We record it, then train a model to dream it. The model gets the last frames and your key press, and it draws the next frame. In the demo below, every frame is generated by the model.

Model: VQ-VAE + 9.8M-parameter spatio-temporal transformer · Runs in your browser

Play inside the dream

The model downloads once (45 MB). It needs a browser with WebGPU (Chrome, Edge, Safari 26) for a smooth frame rate. Without WebGPU, it runs on the CPU at about one frame per second.

How it works

A world model predicts what happens next. Here the world is a small 2D room we wrote: boxes that do not move, a flashlight that you drive, and fireflies that fly on their own. The model learns all of this from recordings only. There is no game code in the demo.

Data

  1. A scripted player drives the flashlight in random rooms.
  2. We record 4,000 episodes of 256 steps: about one million 64 × 64 frames, each with the key that was pressed.

The model

  1. Tokenizer. A VQ-VAE turns each 64 × 64 frame into a 16 × 16 grid of integers, from a codebook of 512 codes.
  2. Context. A Genie-style transformer (9.8M parameters) reads 7 past grids and the keys you pressed.
  3. Attention. Each of the 6 blocks has spatial attention inside a frame, then causal temporal attention across frames.
  4. Positions. 3D rotary position embeddings (row, column, time) tell attention where each token is. This gave the largest improvement.
  5. Output. The model predicts all 256 tokens of the next grid in one pass. The VQ-VAE decoder turns them into the next frame.

Memory and stability

  1. The context mixes recent frames (for motion) and old frames up to 32 steps back (for memory).
  2. The first real frame stays in the context as a fixed memory of how the room looks.
  3. To stop the dream from melting, the model trained on its own predictions and on context with random token noise.

In the browser

  1. We export one transformer step and the decoder to ONNX (45 MB in total).
  2. Each frame is one transformer step and one decoder step in onnxruntime-web: about 35 ms on WebGPU.
  3. The new frame goes back into the context, and the loop repeats.

Papers and links

  • Genie: Generative Interactive Environments (Bruce et al., 2024). The tokenizer + spatio-temporal transformer design.
  • Neural Discrete Representation Learning (VQ-VAE) (van den Oord et al., 2017). The tokenizer.
  • MaskGIT: Masked Generative Image Transformer (Chang et al., 2022). Parallel token prediction with masks.
  • RoFormer: Enhanced Transformer with Rotary Position Embedding (Su et al., 2021). RoPE.
  • World Models (Ha and Schmidhuber, 2018). The original "learn to dream an environment" idea.
  • Diffusion for World Modeling: Visual Details Matter in Atari (DIAMOND) (Alonso et al., 2024). A different method (diffusion) for the same task.
